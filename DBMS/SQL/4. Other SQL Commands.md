# Other Important SQL Commands 

In SQL, apart from the basic CRUD and DDL commands, there are several **clauses and operators** that allow you to **filter**, **group**, **sort**, and **analyze** data more effectively.

This section covers key SQL clauses such as **WHERE**, **HAVING**, **ORDER BY**, **GROUP BY**, **DISTINCT**, **BETWEEN**, **IN**, **LIKE**, **LIMIT**, and more...

---

## 1️⃣ WHERE Clause

The **WHERE** clause filters records that meet specific conditions.

```sql
SELECT * FROM Employees
WHERE Salary > 50000 AND Department = 'HR';
````

### Key Points

* Used with `SELECT`, `UPDATE`, `DELETE`.
* Can combine multiple conditions using:

  * `AND`
  * `OR`
  * `NOT`

---

## 2️⃣ ORDER BY Clause

The **ORDER BY** clause sorts the result set in **ascending (`ASC`)** or **descending (`DESC`)** order.

```sql
SELECT Name, Salary
FROM Employees
ORDER BY Salary DESC;
```

### Key Points

* Default order is **ascending (ASC)**.
* Can sort by multiple columns:

  ```sql
  ORDER BY Department ASC, Salary DESC;
  ```

---

## 3️⃣ GROUP BY Clause

The **GROUP BY** clause groups rows that have the same values into summary rows.
It is often used with **aggregate functions** like `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`.

```sql
SELECT Department, AVG(Salary) AS AvgSalary
FROM Employees
GROUP BY Department;
```

### Key Points

* Every column in `SELECT` (that isn’t an aggregate) must appear in `GROUP BY`.
* Use it to perform aggregate analysis.

---

## 4️⃣ HAVING Clause

The **HAVING** clause filters results after the **GROUP BY** operation.
It is similar to `WHERE`, but works on **aggregate functions**.

```sql
SELECT Department, AVG(Salary) AS AvgSalary
FROM Employees
GROUP BY Department
HAVING AVG(Salary) > 60000;
```

| Clause     | Filters On        | Used With       |
| ---------- | ----------------- | --------------- |
| **WHERE**  | Individual rows   | Before grouping |
| **HAVING** | Aggregated groups | After grouping  |

---

## 5️⃣ DISTINCT Keyword

Removes **duplicate records** from the result set.

```sql
SELECT DISTINCT Department FROM Employees;
```

### Key Points

* Works on single or multiple columns.
* `DISTINCT(Department, JobRole)` gives unique combinations.

---

## 6️⃣ LIMIT / TOP / FETCH

Used to **limit the number of rows** returned by a query.
(SQL syntax may vary slightly between databases.)

```sql
-- MySQL / PostgreSQL
SELECT * FROM Employees LIMIT 5;

-- SQL Server
SELECT TOP 5 * FROM Employees;

-- Standard SQL
SELECT * FROM Employees FETCH FIRST 5 ROWS ONLY;
```

---

## 7️⃣ BETWEEN Operator

Used to filter results within a **specific range**.

```sql
SELECT * FROM Employees
WHERE Salary BETWEEN 40000 AND 80000;
```

### Key Points

* Inclusive of both boundary values.
* Works on **numbers**, **dates**, and **text**.

---

## 8️⃣ IN Operator

Used to match a column against multiple possible values.

```sql
SELECT * FROM Employees
WHERE Department IN ('HR', 'IT', 'Finance');
```

### Key Points

* Acts like multiple OR conditions.
* More readable and efficient than chained `OR`.

---

## 9️⃣ LIKE Operator (Pattern Matching)

Used to search for a specified pattern in a column using **wildcards**.

| Symbol | Meaning                            |
| ------ | ---------------------------------- |
| `%`    | Represents zero or more characters |
| `_`    | Represents exactly one character   |

```sql
SELECT * FROM Employees
WHERE Name LIKE 'A%';     -- Starts with A

SELECT * FROM Employees
WHERE Name LIKE '%n';     -- Ends with n

SELECT * FROM Employees
WHERE Name LIKE '_a%';    -- Second letter is 'a'
```

---

## 🔟 IS NULL / IS NOT NULL

Used to test for `NULL` (missing) values.

```sql
SELECT * FROM Employees
WHERE Email IS NULL;

SELECT * FROM Employees
WHERE Email IS NOT NULL;
```

---

## 1️⃣1️⃣ ALIAS (AS Keyword)

Used to give a temporary name to a column or table.

```sql
SELECT Name AS EmployeeName, Salary AS MonthlySalary
FROM Employees;
```

### Key Points

* Aliases make column names more readable.
* Do not permanently rename columns.

---

## 1️⃣2️⃣ CASE Statement (Conditional Logic)

Acts like an **if-else** statement inside SQL queries.

```sql
SELECT Name,
       Salary,
       CASE
           WHEN Salary > 70000 THEN 'High'
           WHEN Salary BETWEEN 40000 AND 70000 THEN 'Medium'
           ELSE 'Low'
       END AS SalaryCategory
FROM Employees;
```

---

## 1️⃣3️⃣ EXISTS Operator

Checks whether a subquery returns any result.

```sql
SELECT Name
FROM Employees e
WHERE EXISTS (SELECT 1 FROM Departments d WHERE e.DepartmentID = d.ID);
```

### Key Points

* Returns `TRUE` if the subquery returns at least one row.
* Efficient for checking data existence.

---

## 1️⃣4️⃣ ANY / ALL Operators

Used with **subqueries** to compare values.

```sql
-- ANY: True if condition is true for any subquery value
SELECT Name FROM Employees
WHERE Salary > ANY (SELECT Salary FROM Employees WHERE Department = 'HR');

-- ALL: True if condition is true for all subquery values
SELECT Name FROM Employees
WHERE Salary > ALL (SELECT Salary FROM Employees WHERE Department = 'HR');
```
