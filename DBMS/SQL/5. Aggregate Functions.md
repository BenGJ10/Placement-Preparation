# SQL Aggregate Functions

## What Are Aggregate Functions?
**Aggregate functions** in SQL are used to **perform calculations on multiple rows** of a table and return a **single value** as a result.

They are typically used with the **`GROUP BY`** clause to summarize data.

---

## Common SQL Aggregate Functions

## 1. COUNT()
- Returns the **number of rows** (or non-NULL values) in a column.

```sql
SELECT COUNT(*) AS total_students
FROM Students;
````

**Result:**

| total_students |
| -------------- |
| 50             |

You can also count only non-null specific columns:

```sql
SELECT COUNT(CourseID) FROM Students;
```

---

## 2. SUM()

* Returns the **total sum** of numeric column values.

```sql
SELECT SUM(Salary) AS total_salary
FROM Employees;
```

**Result:**

| total_salary |
| ------------ |
| 500000       |

Often used with `GROUP BY`:

```sql
SELECT Department, SUM(Salary) AS total_salary
FROM Employees
GROUP BY Department;
```

---

## 3. AVG()

* Returns the **average (mean)** value of a numeric column.

```sql
SELECT AVG(Marks) AS average_marks
FROM Students;
```

**Result:**

| average_marks |
| ------------- |
| 82.5          |

Example with `GROUP BY`:

```sql
SELECT CourseID, AVG(Marks) AS avg_marks
FROM Students
GROUP BY CourseID;
```

---

## 4. MIN()

* Returns the **minimum value** in a column.

```sql
SELECT MIN(Salary) AS lowest_salary
FROM Employees;
```

**Result:**

| lowest_salary |
| ------------- |
| 25000         |

---

## 5. MAX()

* Returns the **maximum value** in a column.

```sql
SELECT MAX(Salary) AS highest_salary
FROM Employees;
```

**Result:**

| highest_salary |
| -------------- |
| 120000         |

---

## 6. VARIANCE()

* Returns the **statistical variance** of a numeric column.

```sql
SELECT VARIANCE(Salary)
FROM Employees;
```

---

## 7. STDDEV()

* Returns the **standard deviation** of a numeric column.

```sql
SELECT STDDEV(Marks)
FROM Students;
```

---

## Using Aggregate Functions with GROUP BY

The `GROUP BY` clause groups rows that have the same values in specified columns.

```sql
SELECT Department, COUNT(*) AS num_employees, AVG(Salary) AS avg_salary
FROM Employees
GROUP BY Department;
```

**Result:**

| Department | num_employees | avg_salary |
| ---------- | ------------- | ---------- |
| HR         | 10            | 42000      |
| IT         | 20            | 75000      |
| Sales      | 15            | 58000      |

---

## Using Aggregate Functions with HAVING

The **`HAVING`** clause filters groups (unlike `WHERE`, which filters individual rows).

```sql
SELECT Department, AVG(Salary) AS avg_salary
FROM Employees
GROUP BY Department
HAVING AVG(Salary) > 60000;
```

Returns only departments where the average salary is greater than 60,000.

---

## Summary Table

| Function       | Description                    | Example                  |
| -------------- | ------------------------------ | ------------------------ |
| **COUNT()**    | Counts rows or non-null values | `COUNT(*)`, `COUNT(col)` |
| **SUM()**      | Adds up numeric values         | `SUM(Salary)`            |
| **AVG()**      | Calculates mean                | `AVG(Marks)`             |
| **MIN()**      | Smallest value                 | `MIN(Salary)`            |
| **MAX()**      | Largest value                  | `MAX(Salary)`            |
| **VARIANCE()** | Measures variance              | `VARIANCE(Salary)`       |
| **STDDEV()**   | Measures standard deviation    | `STDDEV(Marks)`          |

---

## Key Notes

* Aggregate functions **ignore NULL values** (except `COUNT(*)`).
* Used often with **GROUP BY** to summarize large datasets.
* Use **HAVING** instead of WHERE for conditions on aggregated data.
* Can be combined, e.g.:

  ```sql
  SELECT MIN(Salary), MAX(Salary), AVG(Salary) FROM Employees;
  ```
