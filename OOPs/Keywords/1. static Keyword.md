# `static` Keyword in C++

The **`static` keyword** in C++ controls **lifetime, linkage, and sharing behavior** of variables and functions.

Its meaning **depends on context**, but the core idea remains the same:

> **`static` binds data or behavior to a scope rather than to objects or stack frames.**

---

## 1. Why `static` Exists

Without `static`:

* Variables are created/destroyed frequently
* Each object gets its own copy of members
* Functions may have unnecessary global visibility

`static` enables:

* **Shared state**
* **Persistent storage**
* **Encapsulation**
* **Controlled visibility**

---

## 2. `static` Local Variables

### Definition

A **static local variable**:

* Is initialized **only once**
* Retains its value across function calls
* Exists for the **entire program lifetime**

---

### Example

```cpp
#include <iostream>
using namespace std;

void counter() {
    static int count = 0;
    count++;
    cout << count << endl;
}

int main() {
    counter(); // 1
    counter(); // 2
    counter(); // 3
}
```

✔ Initialized once
✔ Not destroyed after function call
✔ Stored in static memory

---

### Comparison: Normal vs Static Local Variable

| Aspect          | Normal Local  | Static Local   |
| --------------- | ------------- | -------------- |
| Lifetime        | Function call | Entire program |
| Initialization  | Every call    | Once           |
| Memory          | Stack         | Static storage |
| Value retention | ❌ No          | ✔ Yes          |

---

## 3. `static` Data Members (Class Variables)

### Definition

A **static data member**:

* Belongs to the **class**
* Shared by **all objects**
* Exists even if no objects are created

---

### Example

```cpp
class Student {
public:
    static int count;
    Student() {
        count++;
    }
};

int Student::count = 0;  // Definition
```

Usage:

```cpp
Student s1, s2;
cout << Student::count;  // Output: 2
```

✔ Single copy
✔ Shared across objects

---

### Key Rules

| Rule                          | Explanation         |
| ----------------------------- | ------------------- |
| Must be declared inside class | But defined outside |
| Shared across objects         | One copy only       |
| Accessed via class name       | Preferred           |
| Not part of object size       | Memory-efficient    |

---

## 4. `static` Member Functions

### Definition

A **static member function**:

* Belongs to the class
* Can be called **without an object**
* Can access **only static members**

---

### Example

```cpp
class Math {
public:
    static int square(int x) {
        return x * x;
    }
};

int main() {
    cout << Math::square(5);
}
```

✔ No object required
✔ Utility-style function

---

### Restrictions

❌ Cannot access:

* Non-static data members
* `this` pointer

Reason:

* No object context exists

---

## 5. `static` Objects

### Static Object Inside Function

```cpp
void test() {
    static int x = 10;
}
```

* Created once
* Destroyed at program termination

---

### Static Object at Global Scope

```cpp
static int x = 100;
```

* Visible **only within the file**
* Internal linkage

---

## 6. `static` Global Variables and Functions

### Purpose

`static` limits **linkage**, not lifetime.

---

### Example

```cpp
static int globalVar = 10;

static void helper() {
    // accessible only in this file
}
```

✔ Prevents name collisions
✔ Improves encapsulation
✔ Used heavily in large projects

---

## 7. `static` vs `extern`

| Aspect     | static        | extern       |
| ---------- | ------------- | ------------ |
| Linkage    | Internal      | External     |
| Visibility | File-level    | Across files |
| Use case   | Encapsulation | Sharing      |

---

## 8. `static` in Constructors & Destructors

Static members:

* Are **not initialized** in constructors
* Must be defined separately

```cpp
class Test {
    static int x;
};

int Test::x = 10;
```

Static members are destroyed **after `main()` ends**.

---

## 9. `static` and Object Count (Classic Use Case)

```cpp
class Counter {
public:
    static int objects;

    Counter() {
        objects++;
    }

    ~Counter() {
        objects--;
    }
};

int Counter::objects = 0;
```

✔ Tracks live objects
✔ Shared state

---

## 10. `static` with `const` and `constexpr`

### `static const`

```cpp
class A {
public:
    static const int x = 10;
};
```

* Allowed for integral constants
* No separate definition required (in some cases)

---

### `static constexpr` (Modern C++)

```cpp
class A {
public:
    static constexpr int size = 100;
};
```

✔ Compile-time constant
✔ Header-only safe

---

## 11. Common Mistakes

* Forgetting to define static data members
* Accessing non-static members inside static functions
* Assuming static = thread-safe (❌ false)
* Overusing static → hidden dependencies

---

## 12. `static` vs Non-Static Members

| Feature     | Static Member | Non-Static Member |
| ----------- | ------------- | ----------------- |
| Belongs to  | Class         | Object            |
| Copies      | One           | One per object    |
| Access      | Class name    | Object            |
| Uses `this` | ❌ No          | ✔ Yes             |

---

## Key Takeaways

* `static` changes **lifetime, ownership, or visibility**

* Static members belong to the **class, not objects**

* Static functions have **no `this` pointer**

* Static locals preserve state

* Static globals improve encapsulation

* Powerful but should be used **deliberately**
