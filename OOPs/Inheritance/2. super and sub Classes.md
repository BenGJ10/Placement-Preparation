# Superclass and Subclass in C++

In Object-Oriented Programming, **Superclass** and **Subclass** describe the **parent–child relationship** between classes created using **inheritance**.

* **Superclass** → Base / Parent class
* **Subclass** → Derived / Child class

> A **subclass inherits properties and behavior from its superclass**.

---

## 1. What is a Superclass?

A **Superclass** (called a **Base Class** in C++) is the class:

* Whose members are inherited
* That defines **common behavior**
* That represents a **general concept**

```cpp
class Animal {
public:
    void eat() {
        cout << "Eating\n";
    }
};
```

Here:

* `Animal` is the **superclass**
* It defines behavior shared by all animals

---

## 2. What is a Subclass?

A **Subclass** (called a **Derived Class** in C++) is the class that:

* Inherits from a superclass
* Extends or specializes behavior
* Represents a **more specific concept**

```cpp
class Dog : public Animal {
public:
    void bark() {
        cout << "Barking\n";
    }
};
```

Here:

* `Dog` is the **subclass**
* It **is an** `Animal`
* It reuses and extends superclass behavior

---

## 3. Superclass–Subclass Relationship (Is-A)

The relationship between superclass and subclass is an **“is-a” relationship**.

Examples:

* Dog **is an** Animal
* Car **is a** Vehicle
* Circle **is a** Shape

If the statement makes sense logically, inheritance is appropriate.

---

## 4. Basic Example: Superclass and Subclass

```cpp
#include <iostream>
using namespace std;

class Vehicle {        // Superclass
public:
    void start() {
        cout << "Vehicle started\n";
    }
};

class Car : public Vehicle {   // Subclass
public:
    void drive() {
        cout << "Car driving\n";
    }
};

int main() {
    Car c;
    c.start();   // Inherited from Vehicle
    c.drive();   // Own behavior
}
```

✔ Code reuse
✔ Clear hierarchy

---

## 5. Access to Superclass Members

A subclass can access superclass members based on **access specifiers**.

| Superclass Member | Accessible in Subclass |
| ----------------- | ---------------------- |
| `public`          | ✔ Yes                  |
| `protected`       | ✔ Yes                  |
| `private`         | ❌ No                   |

Example:

```cpp
class Base {
private:
    int a;
protected:
    int b;
public:
    int c;
};

class Derived : public Base {
public:
    void test() {
        // a = 1; ❌
        b = 2;     // ✔
        c = 3;     // ✔
    }
};
```

---

## 6. Subclass Extending Superclass Behavior

A subclass can:

* Add new functions
* Override existing functions
* Use inherited functions as-is

```cpp
class Shape {
public:
    virtual void draw() {
        cout << "Drawing shape\n";
    }
};

class Circle : public Shape {
public:
    void draw() override {
        cout << "Drawing circle\n";
    }
};
```

✔ Subclass customizes behavior
✔ Enables runtime polymorphism

---

## 7. Calling Superclass Members from Subclass

Since C++ has **no `super` keyword**, superclass members are accessed explicitly.

```cpp
class Base {
public:
    void show() {
        cout << "Base show\n";
    }
};

class Derived : public Base {
public:
    void show() {
        Base::show();   // Call superclass version
        cout << "Derived show\n";
    }
};
```

✔ Explicit
✔ Avoids ambiguity

---

## 8. Superclass Constructors and Subclass Objects

When a subclass object is created:

1. Superclass constructor runs first
2. Subclass constructor runs next

```cpp
class Base {
public:
    Base() {
        cout << "Base constructor\n";
    }
};

class Derived : public Base {
public:
    Derived() {
        cout << "Derived constructor\n";
    }
};
```

Output:

```
Base constructor
Derived constructor
```

Destruction happens in **reverse order**.

---

## 9. Parameterized Superclass Constructor

```cpp
class Base {
public:
    Base(int x) {
        cout << x << endl;
    }
};

class Derived : public Base {
public:
    Derived() : Base(10) {}
};
```

✔ Base constructor called via initializer list
✔ Equivalent to `super()` in Java

---

## 10. Superclass Pointer to Subclass Object

```cpp
Base* b = new Derived();
```

This enables:

* Polymorphism
* Dynamic binding
* Interface-based programming

```cpp
b->show();  // Calls Derived::show() if virtual
```

---

## 11. What Is NOT Inherited from Superclass

A subclass does **not** inherit:

* Constructors
* Destructors
* Private members
* Friend functions

But:

* Superclass constructors are **automatically invoked**
* Destructor must be **virtual** for polymorphism

---

## 12. Superclass vs Subclass Comparison

| Aspect        | Superclass        | Subclass            |
| ------------- | ----------------- | ------------------- |
| Role          | General           | Specific            |
| Inheritance   | Gives             | Receives            |
| Instantiation | ✔ Allowed         | ✔ Allowed           |
| Polymorphism  | Defines interface | Implements behavior |

---

## 13. Common Design Mistakes

* Using inheritance for code reuse only
* Violating “is-a” relationship
* Forgetting virtual destructors
* Overusing deep inheritance hierarchies

## Key Takeaways

* Superclass defines **common behavior**

* Subclass **inherits and extends** behavior

* Relationship must satisfy **is-a**

* C++ uses explicit base access (`Base::`)

* Constructors run **base → derived**

* Core concept for polymorphism and design
