# Types of Inheritance in C++

**Inheritance** defines how classes are related to each other in a hierarchy.
Based on **how many base classes** and **how inheritance is structured**, C++ supports multiple **types of inheritance**.

> **C++ is one of the few mainstream languages that supports all major inheritance forms.**

---

## 1. Single Inheritance

### Definition

**Single inheritance** involves:

* One base (super) class
* One derived (sub) class

```
Base → Derived
```

---

### Example

```cpp
class Animal {
public:
    void eat() {
        cout << "Eating\n";
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Barking\n";
    }
};
```

✔ Simple
✔ Easy to understand
✔ Most commonly used

---

### Use Cases

* Clear **is-a** relationships
* Small hierarchies
* When only one abstraction is needed

---

## 2. Multilevel Inheritance

### Definition

In **multilevel inheritance**, a class is derived from another derived class.

```
Base → Intermediate → Derived
```

---

### Example

```cpp
class LivingBeing {
public:
    void live() {
        cout << "Living\n";
    }
};

class Animal : public LivingBeing {
public:
    void eat() {
        cout << "Eating\n";
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Barking\n";
    }
};
```

Here:

* `Dog` indirectly inherits from `LivingBeing`

---

### Characteristics

| Feature    | Description         |
| ---------- | ------------------- |
| Depth      | More than one level |
| Code reuse | High                |
| Risk       | Tight coupling      |

---

### Caution

Deep multilevel inheritance:

* Makes debugging hard
* Violates maintainability
* Should be kept shallow

---

## 3. Hierarchical Inheritance

### Definition

In **hierarchical inheritance**, multiple derived classes inherit from a **single base class**.

```
        Base
       /    \
   Derived1  Derived2
```

---

### Example

```cpp
class Shape {
public:
    virtual void draw() = 0;
};

class Circle : public Shape {
public:
    void draw() override {
        cout << "Circle\n";
    }
};

class Rectangle : public Shape {
public:
    void draw() override {
        cout << "Rectangle\n";
    }
};
```

---

### Advantages

✔ Promotes polymorphism
✔ Clean abstraction
✔ Very common in frameworks

---

### Use Cases

* Interface-like base classes
* Plugin systems
* UI components

---

## 4. Multiple Inheritance

### Definition

**Multiple inheritance** allows a class to inherit from **more than one base class**.

```
Base1   Base2
   \     /
    Derived
```

---

### Example

```cpp
class Printer {
public:
    void print() {
        cout << "Printing\n";
    }
};

class Scanner {
public:
    void scan() {
        cout << "Scanning\n";
    }
};

class AllInOne : public Printer, public Scanner {
};
```

Usage:

```cpp
AllInOne obj;
obj.print();
obj.scan();
```

---

### Advantages

✔ Combines multiple behaviors
✔ Powerful abstraction

---

### Risks

❌ Ambiguity

❌ Diamond problem

❌ Complex design

---

### Best Practice

* Use **multiple inheritance sparingly**
* Prefer **interfaces / abstract classes**
* Use **virtual inheritance** when needed

---

## 5. Hybrid Inheritance

### Definition

**Hybrid inheritance** is a **combination of two or more inheritance types**.

Most commonly:

* Combination of **hierarchical + multiple**
* Leads to the **diamond problem**

---

### Structure (Classic Diamond)

```
        A
       / \
      B   C
       \ /
        D
```

---

### Example (Without Virtual Inheritance)

```cpp
class A {
public:
    int x;
};

class B : public A {};
class C : public A {};
class D : public B, public C {};
```

```cpp
D obj;
obj.x = 10;   // ❌ Ambiguous
```

---

## 6. Diamond Problem (Hybrid Inheritance Issue)

### Root Cause

* `D` gets **two copies of A**
* Compiler cannot decide which `A` to use

---

### Solution: Virtual Inheritance

```cpp
class A {
public:
    int x;
};

class B : virtual public A {};
class C : virtual public A {};
class D : public B, public C {};
```

```cpp
D obj;
obj.x = 10;   // ✔ No ambiguity
```

✔ Single shared base
✔ Correct behavior

---

## 7. Virtual Inheritance (Special Case)

### Definition

**Virtual inheritance** ensures:

* Only **one shared instance** of the base class
* Even in multiple inheritance scenarios

---

### Key Rules

| Rule                              | Explanation        |
| --------------------------------- | ------------------ |
| Virtual base created once         | Shared by all      |
| Most derived class initializes it | Not intermediate   |
| Slight memory overhead            | Due to indirection |

---

## 8. Comparison of All Inheritance Types

| Type         | Base Classes | Derived Classes | Complexity | Risk      |
| ------------ | ------------ | --------------- | ---------- | --------- |
| Single       | 1            | 1               | Low        | Low       |
| Multilevel   | 1            | 1 (chain)       | Medium     | Medium    |
| Hierarchical | 1            | Many            | Medium     | Low       |
| Multiple     | Many         | 1               | High       | High      |
| Hybrid       | Many         | Many            | Very High  | Very High |

---

## 9. What C++ Allows vs What Is Recommended

| Feature                  | Supported | Recommended |
| ------------------------ | --------- | ----------- |
| Single inheritance       | ✔         | ✔✔✔         |
| Multilevel inheritance   | ✔         | ✔✔          |
| Hierarchical inheritance | ✔         | ✔✔✔         |
| Multiple inheritance     | ✔         | ⚠️ Limited  |
| Hybrid inheritance       | ✔         | ⚠️ Rare     |

---

## 10. Inheritance vs Composition

> **Favor composition over inheritance** unless:

* Relationship is truly **is-a**
* Base class is designed for inheritance
* Polymorphism is required

Inheritance is **powerful but dangerous** if misused.

---

## Summary Table

| Inheritance Type    | Key Idea                 |
| ------------------- | ------------------------ |
| Single              | One base → one derived   |
| Multilevel          | Chain of inheritance     |
| Hierarchical        | One base → many derived  |
| Multiple            | Many bases → one derived |
| Hybrid              | Combination (diamond)    |
| Virtual inheritance | Solves duplication       |

---

## Key Takeaways

* C++ supports **all major inheritance types**

* Single and hierarchical inheritance are safest

* Multiple and hybrid inheritance require care

* Diamond problem is solved using **virtual inheritance**

* Always validate **is-a** relationship

* Prefer composition when in doubt
