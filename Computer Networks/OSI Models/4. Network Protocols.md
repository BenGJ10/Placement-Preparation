# Important Network Protocols

Network protocols are standardized rules that define **how devices communicate over a network**.

They specify:

* Data format
* Message structure
* Transmission rules
* Error handling
* Connection management

Without protocols, network communication would be chaotic and incompatible across systems.

Protocols operate at different layers of the **OSI model**, but in real-world implementation, they are grouped under the **TCP/IP model**.

---

## 1. Transport Layer Protocols

These protocols ensure **process-to-process communication** between applications.

---

### 1.1 TCP (Transmission Control Protocol)

TCP is a **connection-oriented**, reliable transport protocol.

It ensures that data:

* Is delivered in order
* Is not duplicated
* Is not lost
* Is retransmitted if errors occur

---

#### Key Features

* 3-Way Handshake (connection establishment)
* Sequence numbers for ordered delivery
* Acknowledgments (ACK)
* Flow control (sliding window)
* Congestion control (slow start, congestion avoidance)

---

#### Used In

* Web browsing (HTTP/HTTPS)
* Email (SMTP, IMAP)
* File transfer (FTP)

---

#### When to Use TCP?

When reliability and accuracy are more important than speed.

Example: Banking transactions.

---

### 1.2 UDP (User Datagram Protocol)

UDP is a **connectionless**, unreliable transport protocol.

It sends data without:

* Establishing a connection
* Guaranteeing delivery
* Ensuring order

---

#### Key Characteristics

* Very low latency
* Minimal overhead
* No retransmission
* No congestion control

---

#### Used In

* Online gaming
* Video streaming
* DNS queries
* VoIP

---

#### When to Use UDP?

When speed is more important than reliability.

Example: Live video streaming.

---

## 2. Network Layer Protocols

These handle **logical addressing and routing**.

---

### 2.1 IP (Internet Protocol)

IP is responsible for:

* Logical addressing (IP addresses)
* Packet routing across networks

It does NOT guarantee delivery.

---

#### Types

* IPv4 (32-bit addressing)
* IPv6 (128-bit addressing)

---

#### Important

IP provides best-effort delivery.

Reliability is handled by TCP.

---

### 2.2 ICMP (Internet Control Message Protocol)

#### Purpose

Used for:

* Error reporting
* Diagnostic messages

---

#### Example

* ping command
* traceroute

If a router cannot forward a packet, it sends ICMP error message.

---

### 2.3 ARP (Address Resolution Protocol)

#### Purpose

Maps:

IP address → MAC address

Used inside local networks.

---

#### Process

1. Broadcast ARP request
2. Target device replies with MAC address
3. Mapping stored in ARP table

Without ARP, devices in LAN cannot communicate.

---

### 2.4 Routing Protocols

Used by routers to exchange routing information.

#### Examples

* RIP (Routing Information Protocol)
* OSPF (Open Shortest Path First)
* BGP (Border Gateway Protocol)

BGP is used on the Internet between Autonomous Systems.

---

## 3. Application Layer Protocols

These protocols provide services directly to users and applications.

---

### 3.1 HTTP (HyperText Transfer Protocol)

#### Purpose

Used for web communication.

Client → sends request
Server → sends response

---

#### Characteristics

* Stateless protocol
* Uses TCP
* Runs on port 80

---

### 3.2 HTTPS

HTTP + SSL/TLS encryption.

Provides:

* Confidentiality
* Integrity
* Authentication

Runs on port 443.

---

### 3.3 DNS (Domain Name System)

#### Purpose

Converts:

Domain name → IP address

Example:

google.com → 142.250.x.x

---

#### Works Using

* UDP (usually)
* TCP (zone transfers or large responses)

---

### 3.4 FTP (File Transfer Protocol)

Used for transferring files between client and server.

Runs on:

* Port 21 (control connection)
* Port 20 (data connection)

---

### 3.5 SMTP (Simple Mail Transfer Protocol)

Used for sending emails.

Port 25 (default)

---

### 3.6 POP3 & IMAP

Used for receiving emails.

POP3:

* Downloads and deletes from server

IMAP:

* Synchronizes mail across devices

---

### 3.7 DHCP (Dynamic Host Configuration Protocol)

Automatically assigns:

* IP address
* Subnet mask
* Default gateway
* DNS server

Works using UDP.

---

## 4. Security Protocols

---

### SSL/TLS

Provides:

* Encryption
* Authentication
* Secure communication

Used in HTTPS, FTPS, SMTPS.

---

## 5. Summary Table

| Protocol | Layer       | Purpose            | Reliable?     | Uses              |
| -------- | ----------- | ------------------ | ------------- | ----------------- |
| TCP      | Transport   | Reliable delivery  | Yes           | Web, Email        |
| UDP      | Transport   | Fast delivery      | No            | Gaming, Streaming |
| IP       | Network     | Logical addressing | No            | Routing           |
| ICMP     | Network     | Error reporting    | No            | ping              |
| ARP      | Network     | IP to MAC mapping  | N/A           | LAN communication |
| HTTP     | Application | Web communication  | Depends (TCP) | Websites          |
| HTTPS    | Application | Secure web         | Yes           | Secure browsing   |
| DNS      | Application | Name resolution    | No (UDP)      | Domain lookup     |
| SMTP     | Application | Email sending      | Yes           | Email servers     |
| DHCP     | Application | IP assignment      | No (UDP)      | Network setup     |
| BGP      | Network     | Internet routing   | Yes (TCP)     | ISP routing       |

---

## Key Takeaways

* TCP ensures reliability; UDP ensures speed.

* IP handles addressing and routing.

* ARP connects IP layer to MAC layer.

* DNS translates domain names to IP addresses.

* HTTP/HTTPS power the web.

* Routing protocols maintain Internet structure.

* Security protocols provide encryption and trust.
