# IPv4 Addressing

**IPv4 (Internet Protocol Version 4)** is the most widely used logical addressing scheme in computer networks.  

It operates at the **Network Layer (Layer 3)** of the OSI model and is responsible for **end-to-end delivery of packets across networks**.

IPv4 uses a **32-bit address** to uniquely identify devices on a network.

---

## 1. What is an IPv4 Address?

An IPv4 address is:
> A 32-bit logical address assigned to a device for identification and communication over an IP network.

### Format
- Written in **dotted-decimal notation**
- Divided into 4 octets (8 bits each)

Example:

```
192.168.1.10
```

Binary representation:

```
11000000.10101000.00000001.00001010
```

---

## 2. Structure of IPv4 Address

An IPv4 address consists of:

```
| Network Portion | Host Portion |
```

- **Network ID** → Identifies the network
- **Host ID** → Identifies a device within that network

The division depends on:
- Classful addressing (old method)
- CIDR / Subnetting (modern method)

---

## 3. Total Number of IPv4 Addresses

IPv4 uses 32 bits:

```
2^32 = 4,294,967,296 addresses
```

Due to reserved addresses, actual usable addresses are fewer.

---

## 4. Classful IPv4 Addressing

Originally, IPv4 was divided into **5 classes**:

| Class | First Octet Range | Default Subnet Mask | Purpose |
|-------|------------------|---------------------|---------|
| A | 1 – 126 | 255.0.0.0 | Large networks |
| B | 128 – 191 | 255.255.0.0 | Medium networks |
| C | 192 – 223 | 255.255.255.0 | Small networks |
| D | 224 – 239 | N/A | Multicasting |
| E | 240 – 255 | N/A | Experimental |

---

### 4.1 Class A

#### Range:

```
1.0.0.0 – 126.255.255.255
```

#### Structure:

```
| 8-bit Network | 24-bit Host |
```

#### Usable Hosts per Network:

```
2^24 − 2 = 16,777,214
```

---

### 4.2 Class B

#### Range:

```
128.0.0.0 – 191.255.255.255
```

#### Structure:
```
| 16-bit Network | 16-bit Host |
```

#### Usable Hosts:

```
2^16 − 2 = 65,534
```

---

### 4.3 Class C

#### Range:
```
192.0.0.0 – 223.255.255.255
```

#### Structure:
```
| 24-bit Network | 8-bit Host |
```

#### Usable Hosts:
```
2^8 − 2 = 254
```

---

### 4.4 Class D (Multicast)

```
224.0.0.0 – 239.255.255.255
```

Used for:
- Multicasting
- Not assigned to individual hosts

---

### 4.5 Class E (Experimental)

```
240.0.0.0 – 255.255.255.255
```

Reserved for research

---

## 5. Special IPv4 Addresses

### 5.1 Private IP Addresses

Used inside local networks.

| Class | Private Range |
|-------|--------------|
| A | 10.0.0.0 – 10.255.255.255 |
| B | 172.16.0.0 – 172.31.255.255 |
| C | 192.168.0.0 – 192.168.255.255 |

Used with **NAT (Network Address Translation)**.

---

### 5.2 Loopback Address

```
127.0.0.0 – 127.255.255.255
```

Common:
```
127.0.0.1
```

Used for local testing.

---

### 5.3 Broadcast Address

Used to send packets to **all hosts in a network**.

Example:
```
192.168.1.255
```

---

### 5.4 Network Address

Identifies the network itself.

Example:
```
192.168.1.0
```

Cannot be assigned to host.

---

### 5.5 Default Gateway

Router IP that connects local network to external network.

Example:
```
192.168.1.1
```

---

## 6. Subnet Mask

### Definition
A subnet mask determines:
> Which part of the IP address is network and which part is host.

Example:
```
255.255.255.0
```

Binary:
```
11111111.11111111.11111111.00000000
```

---

## 7. CIDR (Classless Inter-Domain Routing)

Modern addressing does not use classes.

Instead:
```
192.168.1.0/24
```

### Meaning:
- `/24` → first 24 bits are network

CIDR allows:
- Efficient IP allocation
- Flexible subnetting

---

## 8. Types of IPv4 Communication

### 8.1 Unicast
One-to-one communication

### 8.2 Broadcast
One-to-all communication

### 8.3 Multicast
One-to-many selected devices

---

## 9. Limitations of IPv4

- Address exhaustion
- No built-in security
- Limited scalability
- NAT complexity

These led to development of **IPv6**.

---

## Key Takeaways

- IPv4 uses 32-bit logical addressing  

- Originally divided into classes  

- Modern networks use CIDR  

- Private IPs require NAT  

- Broadcast and network addresses are reserved  

- IPv4 exhaustion led to IPv6
